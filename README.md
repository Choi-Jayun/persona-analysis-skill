# persona-analysis — 퍼소나 분석 Claude 스킬

브랜드의 고객 데이터(댓글·리뷰, 매출·구매 데이터, 브랜드·상품 URL, 설문·인터뷰)를 근거로 **매출 의사결정에 쓸 수 있는 퍼소나**를 분석해 HTML 보고서로 만들어 주는 Claude 스킬입니다.

## 분석 내용

| 모듈 | 내용 |
|---|---|
| A. 댓글 → 퍼소나 추출 | 댓글을 상황·욕구·장벽·감정·말투로 분류해 3~5개 퍼소나로 묶고, 퍼소나별 비중과 대표 원문을 제시 |
| B. 충성고객 퍼소나 | 주문 데이터로 RFM 구간을 나눠 충성고객을 숫자로 정의하고, '진입 계기'와 '지속 이유'를 분리 |
| C. 브랜드 접점 | 인지 → 탐색 → 구매 → 사용 → 재구매 5단계 고객 여정에서 접점과 끊기는 지점을 표시 |
| D. 비충성 고객 이유 | 1회 구매 / 재구매 중 이탈 / 관심 후 미구매로 나누고, 장벽을 분류해 "브랜드가 고칠 수 있는가"를 판정 |
| E. 매출 기회 퍼소나 | 기회 점수(규모·구매력·전환 가능성·도달 용이성)로 우선 공략 퍼소나를 선정하고, 계산식 있는 예상 매출과 실행안을 제시 |

### 특징
- **자료가 부족하면 먼저 요청합니다.** 지금 가능한 분석과 필요한 자료를 이유와 함께 체크리스트로 알려줍니다.
- **근거 표시**: 수치와 인용에는 출처를 달고, 추론에는 `가설` 배지를 붙입니다. 받은 자료에 없는 수치는 만들어내지 않습니다.
- **데이터 품질 점검**: 자료 간 불일치(매출 규모, 이상 행 등)를 먼저 찾아 보고서에 밝힙니다.

## 설치

### Claude Code
```bash
git clone https://github.com/Choi-Jayun/persona-analysis-skill.git
```
`persona-analysis` 폴더를 `~/.claude/skills/` 안에 복사하면 새 세션부터 사용할 수 있습니다.

### claude.ai
`persona-analysis` 폴더를 zip으로 압축해 **설정 → 기능(Capabilities) → 스킬**에서 업로드합니다.

## 사용 예시

> 우리 브랜드 퍼소나 분석해줘. 댓글이랑 주문 데이터 넣었어. 누구를 공략해야 매출이 오를지, 충성고객은 어떤 사람들인지, 안 돌아오는 고객은 왜 그런지 알고 싶어.

주문 데이터 컬럼 예시: `주문일, 고객ID(익명), 상품명, 결제금액, 유입채널, 쿠폰사용`
